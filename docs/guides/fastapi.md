# FastAPI integration: zero-key walkthrough

This example sends an HTTP request from a FastAPI route to the bundled fake OpenAI-compatible provider. **No real API key, cloud account, or paid model is required.**

From the repository root, create a virtual environment and install the project plus FastAPI example dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

Open four terminals (activate the same environment in each).

**Terminal 1 — fake provider**

```bash
python examples/fake_openai_provider.py
```

The fake provider listens on `http://127.0.0.1:8000/v1`.

**Terminal 2 — llm-spy**

```bash
llm-spy start --port 8080
```

**Terminal 3 — FastAPI application**

```bash
env -u NO_PROXY -u no_proxy \
  HTTP_PROXY=http://127.0.0.1:8080 \
  http_proxy=http://127.0.0.1:8080 \
  uvicorn examples.fastapi_app_example:app --port 8001
```

Clearing `NO_PROXY` matters: many HTTP clients bypass proxies for loopback hosts by default. The example uses `httpx` with `trust_env=True` to honor the proxy variables.

**Terminal 4 — trigger the endpoint**

```bash
curl --get --data-urlencode 'q=Hello from FastAPI' http://127.0.0.1:8001/ask
```

Expected response shape (the exact wording is generated by the fake provider):

```json
{"answer":"Fake provider saw: Hello from FastAPI"}
```

Inspect the captured request:

```bash
llm-spy history
llm-spy dashboard
```

The dashboard URL is printed by the command. The captured request is **HTTP**, so the HTTPS certificate setup is unnecessary for this local example.

## Troubleshooting

- **Nothing captured?** Confirm `HTTP_PROXY` is set in the **FastAPI process**, and `NO_PROXY`/`no_proxy` are unset. Run `llm-spy doctor`.
- **Connection refused?** Check that the fake provider uses port 8000, llm-spy uses 8080, and uvicorn uses 8001.
- **502 from /ask?** The example deliberately returns a generic error without exposing upstream details; inspect the fake-provider and proxy terminals.
- **Using a real HTTPS provider instead?** Configure your provider credentials separately, set `HTTPS_PROXY`, and follow [HTTPS setup](../quickstart.md#https-setup). Never commit API keys.

This is a development demonstration, not a production deployment guide.
