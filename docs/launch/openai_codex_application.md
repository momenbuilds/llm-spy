# OpenAI Codex for Open Source Application

Project: llm-spy.

llm-spy is a local-first LLM API inspector that improves the OpenAI developer experience by making API calls visible in real time. It helps developers debug prompts, tool calls, response formats, latency, token usage, and costs without requiring SDK instrumentation.

It supports OpenAI chat completions and Responses API parsing. OpenAI credits would help test compatibility across models and maintain high-quality examples.
