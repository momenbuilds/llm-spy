# Prelaunch Checklist

- Fresh clone test.
- `pip install -e .`.
- `llm-spy --help`.
- `llm-spy start --help`.
- Run examples.
- Test OpenAI capture.
- Test Anthropic capture.
- Test dashboard.
- Test export.
- Review Windows/macOS/Linux notes.
- Ask one external cold tester to install and run.
- Do not launch until one person tests a cold install.
