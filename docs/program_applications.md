# Program Applications

## OpenAI Codex for Open Source

llm-spy is a local-first LLM API inspector for AI developers. It improves the OpenAI developer experience by making request/response debugging visible without SDK instrumentation. Developers can inspect prompts, tools, latency, token usage, and estimated cost locally, which helps them debug faster and catch cost overruns earlier.

API credits would support testing across OpenAI models and realistic examples without storing user data or adding telemetry.

## Anthropic Credits

llm-spy supports Claude Messages API parsing, system prompts, usage, stop reasons, and tool fields. It helps developers understand model behavior, maintain a local audit trail, detect PII patterns, and warn about prompt injection attempts.

Credits would help maintain parser compatibility and responsible AI development examples.
