# Users

If you use llm-spy in a project and want to share it, open a PR with an entry.

## Format

```markdown
- Project: Example project name
  Link: https://example.com
  Use: Local LLM API debugging during development
```

The example above is a format example only, not an adoption claim. Do not add fake users, fake company logos, or fake metrics.

Privacy note: only share projects that are comfortable being listed publicly.
